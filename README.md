# Контроль металла

Веб-приложение для проверки соответствия рулона металла требованиям производственной накладной перед прокаткой. Решает ровно одну задачу: «этот рулон соответствует требуемому материалу или нет?» — по четырём характеристикам (RAL, толщина, производитель, покрытие).

Не CRM, не ERP, не складская система. См. [ARCHITECTURE.md](ARCHITECTURE.md), раздел «Что сознательно не реализуется».

## Стек

Next.js (App Router) + TypeScript, PostgreSQL + Prisma, Docker, деплой на Timeweb Cloud. Один проект — фронтенд и API вместе (обоснование в ARCHITECTURE.md).

## Быстрый старт (появится с Iteration 1)

Проект пока не инициализирован — сейчас завершён этап архитектурного анализа. Разработка стартует с Iteration 1 согласно DEVELOPMENT_PLAN.md.

## Ключевой принцип

**Fail closed.** Любая неопределённость, отсутствующее или нераспознанное значение — всегда результат СТОП, никогда не «предположительно можно».
